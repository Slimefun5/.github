# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report them privately via [GitHub's private vulnerability reporting](../../security/advisories/new) or by reaching a maintainer on our [Discord](https://discord.gg/CbBYZBEWdR).

We will acknowledge your report as quickly as we can and keep you updated on the fix.

## Supported versions

Only the latest release of each Slimefun5 repository receives security fixes.
