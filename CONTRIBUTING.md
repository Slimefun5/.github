# Contributing

Thanks for your interest in contributing to Slimefun5! This applies to the core plugin and every addon in the [Slimefun5](https://github.com/Slimefun5) organisation.

## Reporting bugs

Open a [Bug Report](../../issues/new/choose) issue. Include your `/sf versions` output, your Minecraft/server version, clear steps to reproduce, and any console errors.

## Suggesting features

Start a thread on our [Discord](https://discord.gg/CbBYZBEWdR) so we can discuss the idea before you invest time in a pull request.

## Pull requests

1. Fork the repository and create a branch off the development branch (`experimental`).
2. Match the existing code style; keep changes focused and small.
3. Add `@Nonnull` / `@Nullable` annotations where appropriate.
4. Make sure the project still builds and existing behaviour is preserved.
5. Open the pull request against `experimental` and fill out the template.

## Code of Conduct

By participating you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
